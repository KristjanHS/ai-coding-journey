# Evaluating code models

A source thread from the experiments band, before any tool had been committed
to. The subject is not a product comparison — it is the measuring apparatus: the
benchmarks and metrics that let "this model completes code better" mean
something checkable rather than a feeling.

What puts this topic at the asking rung is that the first move was to ask for
the map, not the answer. You reach for the vocabulary of evaluation — pass@k,
token accuracy, tests passed — before you are in any position to rank a tool.
