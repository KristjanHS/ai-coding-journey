# Cursor rules

Named after the feature itself: the `.cursor/rules/*.mdc` files an editor
prepends to the model's context. What groups the threads here is not the
feature but how it was learned. The question asked was how rules behave when
the agent runs on a bring-your-own-key model, and the answer that came back
described the directory, the frontmatter, the injection order and the scoping —
each point carrying a link to the vendor's own documentation.

That is the asking rung's characteristic shape. The answer is checkable, because
the citation resolves; it is not verified, because nothing in the exchange was
run against the editor sitting on the desk. The atoms here name what that
distinction costs.
