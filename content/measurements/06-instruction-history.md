# Instruction-file history

The repos' git histories date the agent instruction layer: root files, Cursor rules, and Claude Code
rules, skills, hooks, agents and settings. Every figure below is generated by
`scripts/instruction-history.py` into `data/instruction-history.json`, read to each repo's current
HEAD, and pinned against this file by a test: a regen that moves a figure reds the gate until this
page carries the new value.

- Measured how: `git log` over every repo in `scripts/repos.json`, one pathspec per file class, by
  author date; line counts are the global CLAUDE.md at the last commit of each day that touched it.

## First appearance

11 classes of instruction file appear across the 15 repos. The first `.cursor/rules/` file was
committed on 2025-07-31 in kri-local-rag; the first `CLAUDE.md` followed on 2026-03-29 in proj-mgmt.
Setup that outlives the session is older than Claude Code in this history, not a feature it brought.

## The global CLAUDE.md

The global CLAUDE.md measured 57 lines on 2026-04-05, peaked at 127 lines on 2026-07-16, and was cut
back to 81 lines by 2026-09-08. Every session loads this file, so the cut is a cost decision: the lines
removed moved into path-gated rules and references that load only when needed.

## Fleet sweeps

On 2026-09-06, instruction files changed in 12 of the 15 repos on the same day. Days reaching the
5-repo threshold: 1. That day is when the ignore-file deny list moved into `.claude/settings.json`
across the fleet — one control, pushed everywhere at once.

That sweep also sets the latest instruction-file date for nearly every repo, so a repo's last
instruction change is never read as its last working day.

## What is not published

Not published: the global CLAUDE.md's content and path (it lives in the private dotfiles repo), any
commit SHA of a private repo, and per-repo commit counts. Only dates, line counts, repo names and
repo counts leave the histories.
