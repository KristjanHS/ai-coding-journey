# Climb one rung

A one-page worksheet for the lecture. It is not graded and there is no schedule. You
fill it in for your own work, then keep it.

## Part A · Climb one rung

**Circle your rung.** Which unit of instruction do you hand the agent most days?

asking · suggesting · delegating · planning · configuring · governing

**Box the one file you would add to reach the next rung.** Not a tool, not a habit — one
file you could commit. If nothing comes to mind, you are probably one rung lower than you
circled.

**Box the check that fails if it stops working.** A rung you cannot lose is a rung you
have not really reached: name the test, the review step or the hook that goes red the day
the file is ignored.

**Worked answer (the author's own, planning → configuring).** At planning, the one file
that reaches configuring is a plan doc per increment, and the check that fails if it stops
working is review sending the plan back. The plan is reviewed before any code exists, and
the reviewer's job is to reject a draft that argues its design forward while listing
nothing it rejected — the part a reader needs six months later.

## Part B · The ladder on one page

| rung | from | unit of instruction | you're here if… | the next move |
| --- | --- | --- | --- | --- |
| asking | 2025-06 | a question | you paste code in and out of a chat window | keep the reply, and move the working prompt into a file |
| suggesting | 2025-06 | a snippet | an editor finishes the line as you type | hand over a whole task, not a line |
| delegating | 2025-07 | a task | you name a task and read back the diff | write the plan before the task, not after |
| planning | 2026-02 | a plan | you approve a plan doc before any code is written | move the standing rules out of the plan and into config |
| configuring | 2026-04 | a policy | rules, skills and hooks load before the first token | make a check go red when a policy stops holding |
| governing | 2026-07 | a process | you review the system, not the diff | write the gate that fails when the system stops holding |

The rung and the two dates in each row come from the site's own ladder table; the last two
columns are for you to argue with.
