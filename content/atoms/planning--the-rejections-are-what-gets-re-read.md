# The rejections are what gets re-read

A plan committed next to the code splits the record in two. The code holds the
design that won; the plan holds the options that lost and why each one lost.
The second half cannot be recovered from the first.

In the shipped plan, two of the three rejections were about legibility rather
than capability, and both alternatives would have worked. Only the plan says so.
