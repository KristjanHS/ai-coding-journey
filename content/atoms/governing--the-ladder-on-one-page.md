# The ladder on one page

Six rungs, named by the unit of instruction you hand the agent. The two left columns are
the site's own dates; the right two are what you fill in.

| rung | from | unit of instruction | you're here if… | the next move |
| --- | --- | --- | --- | --- |
| asking | 2025-06 | a question | you paste code in and out of a chat window | keep the reply, and move the working prompt into a file |
| suggesting | 2025-06 | a snippet | an editor finishes the line as you type | hand over a whole task, not a line |
| delegating | 2025-07 | a task | you name a task and read back the diff | write the plan before the task, not after |
| planning | 2026-02 | a plan | you approve a plan doc before any code is written | move the standing rules out of the plan and into config |
| configuring | 2026-04 | a policy | rules, skills and hooks load before the first token | make a check go red when a policy stops holding |
| governing | 2026-07 | a process | you review the system, not the diff | write the gate that fails when the system stops holding |
