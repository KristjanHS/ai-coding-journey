# Climb one rung

The worksheet turns the ladder into one move: circle your rung, box the one file that
reaches the next one, box the check that fails if that file stops working. A rung you
cannot lose to a broken check is a rung you have not really reached.

## Evidence

> [2026-09-11] "At planning, the one file that reaches configuring is a plan doc per increment, and the check that fails if it stops working is review sending the plan back."
