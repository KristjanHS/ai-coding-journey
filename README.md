# ai-coding-journey

One person's path from a 20-year coding pause to shipping a ~5k-commit app with AI coding agents,
written as a public, markdown-first knowledge base.

For engineers and managers who want the method and the governance, not a demo. The author does not
read the generated code; the chapters show the review system instead and what it caught.

Start at [`content/journey/`](content/journey/README.md): one chapter per repo, in the order the repos
were started. Every chapter carries at least one real artifact (a prompt, a rule, a caught defect, a
measured number) and a *What didn't work* section. Failures get equal billing.

A browsable site and a lecture deck come later; the markdown here is the product.
